## Android Studio - Web Layout Edition:<br>
is [Android layout XML](https://developer.android.com/courses/android-basics-compose/course) viewer - you write code [in android layout xml](https://developer.android.com/courses/android-basics-compose/course), and when you finish and run the emulator, here's what happens: a `api/index.py` file takes you **XML** code and converts it into JSON. The frontend catches the JSON and uses it to display the emulation on the **site**. For those who wanted to test layouts online or avoid overloading their computer with heavy `Android Studio`, welcome to my [**website!**](https://android-layout-xml-viewer.vercel.app)

## Андроид Студио - Веб-лайаут версия:<br>
это [андроид лайаут xml](https://developer.android.com/courses/android-basics-compose/course) просмотрщик - ты пишешь код [на андроид лайаут xml](https://developer.android.com/courses/android-basics-compose/course), и когда ты написал и запускаешь эмутяор то происходит следующее: `api/index.py` питон файл берёт твой написанный **XML** код и контервирует в JSON, фрондент ловит JSON и с помощью его **сайт** показывает эмуляцию. Те кто хотели протестировать онлайн или не нагружать комп тяжелым `андроид студио`, приходите на мой [сайт](https://android-layout-xml-viewer.vercel.app/)!<br>
